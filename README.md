 # Nepali Calendar Hub

 A modern hub for exploring Nepali dates, calendar information, festivals, holidays, and related resources.

 ## Features

 - Nepali (Bikram Sambat) calendar support
 - Nepali and Gregorian date references
 - Festival and public holiday information
 - Clean, responsive experience
 - Useful resources for planning and date conversion

 ## Getting started

 Clone the repository and install its dependencies:

 ```bash
 git clone https://github.com/<your-username>/nepali-calendar-hub.git
 cd nepali-calendar-hub
 npm install
 ```

 Start the development server:

 ```bash
 npm run dev
 ```

 Open the local URL shown in your terminal.

 ## Available scripts

 | Command | Description |
 | --- | --- |
 | `npm run dev` | Start the development server |
 | `npm run build` | Create a production build |
 | `npm run preview` | Preview the production build locally |
 | `npm run lint` | Check the codebase for lint issues |
